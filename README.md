# Дневник

Личный дневник в формате тетради в клетку: неделя на одном экране.
Пн–Ср слева, Чт–Сб справа, воскресенье — полоса внизу на всю ширину.

Ничего устанавливать не нужно: это обычная HTML-страница, которая открывается в Microsoft Edge
как отдельное окно во весь экран.

## Установка

1. Склонировать репозиторий в постоянную папку (например `Documents\GitHub\paper-diary`).
2. Запустить `install.cmd` — появится ярлык **«Дневник»** на рабочем столе и в «Пуске»,
   горячая клавиша **Ctrl+Alt+D**.

Если папку с репозиторием переместить — снова запустить `install.cmd`.

## Как пользоваться

- Клик в любое место дня — запись начинается прямо там.
- Ctrl + колесо (или Ctrl+= / Ctrl+-) — размер текста.
- Alt + колесо — повернуть запись (с Shift — по 1°), кнопка ⟂ — писать боком.
- Alt + тянуть за текст или за ✥ — передвинуть запись (можно и в другой день).
- Кружок в правом углу дня — настроение.
- Alt+← / Alt+→, PageUp / PageDown — листать недели; Alt+Home — текущая неделя.
- Клик по датам сверху — перейти к любой дате.
- При запуске открывается последняя недозаполненная неделя.

## Где лежат данные и бэкапы

Записи хранятся в отдельном профиле Edge: `%LOCALAPPDATA%\PaperDiary\EdgeProfile`
(очистка истории в обычном Edge их не затронет).

Меню ☰:
- **Экспорт в файл (.json)** — полный бэкап.
- **Импорт из файла** — объединить с текущими записями или заменить всё.
- **Экспорт в текст (.txt)** — читаемая выгрузка по дням.
- **Файл автобэкапа** — выбрать файл (лучше в OneDrive / на флешке), дневник будет
  перезаписывать его при каждом изменении. После перезапуска Edge может попросить
  подтвердить доступ — сверху появится кнопка «автобэкап на паузе — включить».

Файлы бэкапов (`*.json`) в git не попадают — см. `.gitignore`.
